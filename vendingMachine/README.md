# 自動販売機システム (Vending Machine System)

PHPを用いたオブジェクト指向プログラミング（OOP）の学習用コンソールアプリケーションです。  
現実世界の自動販売機の仕組みを題材に、クラス設計・カプセル化・継承・ポリモーフィズムといったOOPの基本概念を実践・理解することを目的としています。

---

## 🎯 学習目的

- **クラスとインスタンス**: 設計図（Class）から実体（Instance）を生成して扱う
- **カプセル化（Encapsulation）**: アクセス修飾子（`private` / `protected`）を使い、不正な状態変更を防ぐ
- **継承（Inheritance）**: 共通の処理を親クラスにまとめ、子クラスで機能を拡張する
- **ポリモーフィズム（Polymorphism）**: 異なるオブジェクトを共通のインターフェースで操作する

---

## 🛠 仕様・機能一覧

### 1. ドリンク（Drink）
- 名前（`name`）と価格（`price`）を保持する
- 価格や名前は外部から直接書き換えられないよう保護（カプセル化）

### 2. 自動販売機（VendingMachine）
- **お金の投入**: コインや紙幣を投入し、投入金額（`balance`）を加算する
- **在庫管理**: 販売可能なドリンクの一覧と在庫数を管理する
- **購入可能判定**: 投入金額と在庫数から、指定された商品が購入可能か判定する
- **購入処理**:
  - 投入金額から商品の価格を差し引く
  - 在庫を1つ減らす
  - ドリンクオブジェクトとお釣りを返却する
- **売上管理**: これまでの総売上（`sales`）を内部で保持する
